# Verhaltenskodex

Wir möchten eine sachliche, respektvolle und sichere Zusammenarbeit ermöglichen.

## Erwartetes Verhalten

- konstruktive, nachvollziehbare technische Kritik
- respektvoller Umgang unabhängig von Erfahrung oder Hintergrund
- verantwortungsvolle Behandlung möglicher Sicherheitslücken
- Schutz privater Daten anderer Personen

## Nicht akzeptiert

- Beleidigungen, Belästigung oder persönliche Angriffe
- Veröffentlichung fremder Schlüssel, Onion-Adressen oder anderer sensibler Daten
- Druck auf meldende Personen, Sicherheitsdetails vor einer Behebung offenzulegen
- absichtliche Störung von Diskussionen oder Infrastruktur

Moderierende Personen dürfen Beiträge bearbeiten, sperren oder entfernen, wenn sie diesen Regeln widersprechen. Vorfälle sollten privat an die Repository-Verantwortlichen gemeldet werden.
